The CrashPulse app

CrashPulse works entirely on your Mac. It has no account, no analytics and no crash reporting, and it does not send anything over the network.

  • To find busy apps, it reads process names, process IDs, app locations, CPU use, memory use and, on Apple silicon, CPU energy, using the same system interfaces as Activity Monitor.
  • It keeps a history of CPU events for the last seven days in ~/Library/Application Support/CrashPulse. Settings are kept in the app's standard preferences.
  • It does not read your files, documents, browsing history, keystrokes or screen, and it asks for no privacy permissions.
  • If you export a report from Settings, the file can include process names, process IDs and app locations. It is saved where you choose and only leaves your Mac if you share it.

To delete everything CrashPulse has stored, quit the app and delete the folder above.
